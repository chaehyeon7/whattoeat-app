# 뭐먹지 (WhatToEat) 기획서 v1.0

## 1. 서비스 개요

| 항목 | 내용 |
|------|------|
| 앱 이름 | 뭐먹지 |
| 프로젝트명 | whattoeat |
| 플랫폼 | Android / iOS (Flutter) |
| 목적 | AI 기반 점심 메뉴 추천 + 냉장고 재료 기반 요리 추천 |
| 타깃 | 매일 "뭐 먹지?" 고민하는 직장인·자취생 |

## 2. 핵심 기능

### 탭 1: 🥕 냉장고
내가 가진 재료를 등록·관리하는 저장소

- 재료 추가 (텍스트 입력)
- 재료 삭제
- 카테고리별 분류 (채소, 육류, 해산물, 양념, 기타)

### 탭 2: 🎰 오늘 뭐먹지
조건 선택 → AI가 추천 → 사먹기 + 해먹기 동시 표시

**필터 조건:**
| 필터 | 선택지 |
|------|--------|
| 무게감 | 가벼운 / 보통 / 든든한 |
| 종류 | 한식 / 일식 / 중식 / 양식 / 분식 / 동남아 |
| 상황 | 혼밥 / 회식 / 데이트 / 안주 / 해장 |
| 가격대 | ~8천 / ~1.5만 / 상관없음 |

**추천 결과 (한 화면에 동시 표시):**

🏪 **사먹기** — 내 위치 주변 실제 음식점에서 AI가 골라줌
- 음식점명, 거리, 카테고리
- AI 추천 이유
- 지도보기 / 전화 버튼

🍳 **해먹기** — 냉장고 재료 기반 AI 추천
- 요리명, 필요 재료 (보유/미보유 표시)
- AI 추천 이유 + 간단 레시피
- 자세한 레시피 보기

## 3. 사용자 흐름

### 흐름 A: 사먹기
```
필터 선택 → [추천받기] 탭
→ GPS로 내 위치 확인
→ 카카오 API로 주변 음식점 검색
→ Gemini AI에게 음식점 목록 + 조건 전달
→ AI가 조건에 맞는 음식점 2~3개 추천
→ 화면에 표시 (지도보기·전화 연결)
```

### 흐름 B: 해먹기
```
필터 선택 → [추천받기] 탭
→ 냉장고 등록 재료 불러오기
→ Gemini AI에게 재료 + 조건 전달
→ AI가 만들 수 있는 요리 2~3개 추천 (레시피 포함)
→ 화면에 표시
```

### 흐름 C: 냉장고 관리
```
탭 1 진입 → 재료 목록 표시
→ [+] 버튼으로 재료 추가
→ 스와이프로 재료 삭제
```

## 6. API 연동 상세

### Gemini API 프롬프트 설계

**사먹기 프롬프트:**
```
당신은 점심 메뉴 추천 전문가입니다.

[조건]
- 무게감: {가벼운}
- 종류: {한식}
- 상황: {혼밥}

[내 주변 음식점]
{카카오 API 검색 결과}

위 음식점 중 조건에 맞는 곳 2~3개를 추천해주세요.
각 추천에 한 줄 이유를 포함해주세요.
JSON 형식으로 응답해주세요.
```

**해먹기 프롬프트:**
```
당신은 요리 추천 전문가입니다.

[조건]
- 무게감: {가벼운}
- 종류: {한식}

[내 냉장고 재료]
{계란, 파, 김치, 참치캔, 밥}

위 재료로 만들 수 있는 요리 2~3개를 추천해주세요.
각 요리에 간단한 레시피(3줄 이내)와 추천 이유를 포함해주세요.
JSON 형식으로 응답해주세요.
```

### 카카오 로컬 API
```
GET https://dapi.kakao.com/v2/local/search/keyword.json
  ?query={AI가 선정한 키워드}
  &x={경도}&y={위도}
  &radius=1000
```

## 7. 데이터 모델

### 냉장고 재료
```
ingredients/
  {userId}/
    {ingredientId}/
      name: "계란"
      category: "기타"  // 채소/육류/해산물/양념/기타
      createdAt: timestamp
```

### 추천 히스토리 (선택)
```
history/
  {userId}/
    {historyId}/
      type: "eat_out" | "cook"
      filters: { weight: "가벼운", cuisine: "한식", ... }
      result: "..."
      createdAt: timestamp
```
